## Draft 1 — Harness runtime context

Quick builder note: an Agent SDK gives you the model loop, but production
operation needs a runtime layer around it.

MCP handles tool connection. A sandbox handles process isolation. The Harness
layer handles the things that make an Agent repeatable and governable: persistent
sessions/workspaces, permission boundaries, failure handling, audit, and replay.

If you are evaluating an Agent stack, ask what happens when a session resumes,
credentials need to be narrowed, or a tool fails halfway through a task. Those
answers are part of the product behavior, not just deployment details.

SandBase Harness is a local-first implementation you can inspect here:
https://github.com/sandbaseai/sandbase-harness

If you try it, share the setup, runtime, or permission edge case that you hit in
this channel. This is a draft for review; it is not yet a published update.
