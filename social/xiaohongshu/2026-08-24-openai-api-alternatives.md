## 选题钩子

“OpenAI API 替代方案”不是一个产品类别，而是五种不同的替换问题。

## 4–8 页图文结构

1. 封面：OpenAI API 替代方案，先别急着看价格
2. 你要替换的是模型、供应商、SDK、网关，还是图片/视频/工具能力？
3. Anthropic / Gemini：直接换一家模型供应商
4. SandBase / OpenRouter：托管的多供应商调用面
5. LiteLLM：自己运维的代理层；Portkey：网关、观测和策略控制
6. 兼容 OpenAI SDK ≠ 每个参数和行为都完全相同
7. 选择清单：模型优先、托管多模型、自托管、治理控制、统一多模态 API
8. 结尾：查看完整对比和迁移检查

## Caption

真正要先问的不是“哪家最便宜”，而是“我到底在替换什么”。这份对比把 Anthropic、Gemini、SandBase、OpenRouter、LiteLLM 和 Portkey 放在同一张决策表里，也标出 OpenAI-compatible 的边界。
