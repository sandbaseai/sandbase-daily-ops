## 二、选题策略评价

### 做对了什么

1. **#27/#30 命中了超级大词**（image to video AI, 40,500/月）— 这两篇如果排进前 10 能带来大量流量
2. **#21 精准切入细分**（anthropic prompt caching, 390/月, LOW）— 小量但竞争极低，大概率能排前 3
3. **#16 时效热度**（gpt 5.6 release, 110/月）— 新模型发布期搜索暴涨，先进先排
4. **#8 抓住了强意图词**（LLM API cost comparison, CPC $9.18）— 搜这个的人大概率要买
5. **覆盖了 3 个零竞争分类**（pricing-guides, industry-insights, agent-best-picks）— 站内从 0 到有

### 可以改进什么

1. **社媒 API 类选题在美国市场没有搜索量** — 这 12 篇的 SEO 流量预期很低（美国市场）。但中国市场未验证，可能是中文 SEO 的机会。
2. **太多模型对比词还没起量** — claude opus 5、sonnet 5、kimi k3 这些模型太新，搜索习惯还没形成。这些文章是"等风来"型资产——3-6 个月后搜索量起来时我们已经有内容了。
3. **SERP 意图错配** — "best LLM for AI agents" 的 SERP 全是 agent 框架文（LangChain、CrewAI），不是 LLM 选型文。我们的 #22 标题方向需要调整为更贴近"agent framework"视角。
4. **缺少已有大量词的覆盖** — "image to video AI" 旁边还有一系列相关大词我们没覆盖（如 "AI video generator", "text to image AI" 等），应该补。

## 五、建议：下一批文章选题流程

```
DataForSEO 先行 → 确认有量 → 再写文章
```

不再是"先选题再验证"，而是：

1. 用 DataForSEO 批量查 50-100 个候选关键词的搜索量
2. 筛选出 月搜 > 50 且 竞争 ≤ MEDIUM 的词
3. 围绕这些词设计选题
4. 写文章时标题精确包含目标关键词
5. 发布后 2 周用 DataForSEO 追踪排名变化

这样每篇文章写之前就知道它的流量天花板，避免写出搜索量为 0 的内容。
