# SandBase Promotion Plan

This directory is the starting context and audit trail for continuous SandBase promotion.

1. Read [`master-context.md`](master-context.md) before planning or publishing.
2. Execute the applicable checks in [`daily-audit.md`](daily-audit.md).
3. Make implementation changes in the repository that owns the surface.
4. Record actions, evidence, deployment state, metrics, and follow-up date under [`logs/`](logs/).
5. Update the master context when a product claim, URL, owner, audience, or channel role changes.

The objective is a verified **100× increase in rolling 28-day non-brand Google clicks**, from the frozen baseline of **119** to **11,900**. This is a long-term outcome, not a claim that any single article or release will deliver 100× growth.

Secrets, access tokens, service-account JSON, private customer information, and unpublished credentials never belong in this directory.
